# AI Monitor Models (Edge AI Detection Models)

本仓库用于托管网络监控摄像头客户端本地实时目标检测模型的版本配置与二进制权重。

## 支持检测目标
- 🚶 **人 (Person)**
- 🐱 **猫 (Cat)**
- 🐶 **狗 (Dog)**
- 🔥 **火 (Fire / Flame)**

## 当前版本
- **版本号**：`v1.0` (version: 1)
- **模型基座**：YOLOv8n 轻量级检测模型 (~6.2MB)
